# Frontend Standards

- **Library discipline (critical):** if a UI library (Shadcn, Radix, MUI, etc.) is present, use it. Never rebuild modals, dropdowns, buttons from scratch. Wrapping/styling library primitives is fine.
- Stack: React/Vue/Svelte, Tailwind or custom CSS, semantic HTML5.
- Care about micro-interactions, spacing, and invisible UX. Delete elements with no purpose.
